GESTÃO ESCOLAR - COMO EXECUTAR

1. Instale o Python 3.
2. Abra um terminal dentro desta pasta.
3. (Opcional, recomendado) crie um ambiente virtual:
   Windows: py -m venv .venv
   Windows: .venv\Scripts\activate
   macOS/Linux: python3 -m venv .venv
   macOS/Linux: source .venv/bin/activate
4. Instale a dependência:
   pip install -r requirements.txt
5. Inicie o site:
   Windows: py app.py
   macOS/Linux: python3 app.py
6. Abra no navegador:
   http://127.0.0.1:5000

Os registros são armazenados no arquivo dados.txt nesta mesma pasta.
Não apague o arquivo enquanto o programa estiver em uso.
